# NAAS: Not Another AI System
**Empathic State Machine for Gentle Consultation**

## Overview
NAAS is a system designed to make consultations on work improvement or idea generation easier and less stressful.  
It responds gently when users hesitate or are unsure, suggesting retries or skipping when needed.  
Consultation content is organized step by step and fully recorded, allowing for later review and analysis.  
Even blank or uncertain answers are met with empathy, and the system adjusts what to ask next.

## Features
- Step-by-step questioning
- Gentle retry with optional skip
- Organizes and records responses for review
- Responds empathetically to blank or uncertain answers

## Use Cases
- Improving hospital wait times
- Organizing and analyzing team challenges
- Brainstorming new project ideas

Even vague or undeveloped ideas can be gradually clarified, enabling consultations in a psychologically safe environment.

## How to Use
1. Clone the repository or download the code.
2. Prepare a flow configuration dictionary with your questions and prompts.
3. Run `EmpathicStateMachine` with the flow configuration.
4. Follow the prompts and answer step by step.
5. Responses will be saved in `naas_memory.json` for later analysis.

## Installation
- Python 3.7+
- No external dependencies required beyond the standard library
